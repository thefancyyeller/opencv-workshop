# OpenCV Workshop

Jupyter notebooks for experimenting with OpenCV.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```powershell
jupyter lab
```

Or open `notebooks/01_getting_started.ipynb` in VS Code and select the `.venv` kernel.

## Layout

- `notebooks/` — Jupyter notebooks
- `images/` — input images
